# ♻️ Decay Market

### **Rescue surplus before it becomes waste.**

Decay Market is an AI-powered marketplace for resources whose value decreases over time — from bakery surplus and flowers to fabric off-cuts, opened paint, and damaged building materials.

Instead of using a fixed discount, **Decay Market uses AI to understand the item, estimate its condition and value, and select a price-decay curve based on how quickly that resource is losing value.**

**The core idea:**

> **Resource decay → AI understands decay → Price decays → Buyer urgency → Resource gets rescued**

### How it works

1. **📸 List in seconds** — upload a photo and describe the surplus by text or voice.
2. **🤖 AI understands it** — generates the listing, estimates condition, value and urgency.
3. **📉 Price decays over time** — the price follows a curve appropriate to the resource.
4. **🔥 Buyers discover surplus** — live prices and urgency make time-sensitive opportunities visible.
5. **🤝 Claim & rescue** — buyers claim the resource and arrange pickup before it becomes waste.

### Why Decay Market?

Traditional marketplaces treat inventory as static.

But surplus isn't static — **its value changes with time.**

A croissant that needs to be consumed today, a bouquet that will wilt tomorrow, and a stack of reusable tiles that can sit for weeks should not follow the same pricing logic.

Decay Market turns that difference into the marketplace mechanism itself.

### Core Technologies

* AI-powered listing generation
* AI condition and value estimation
* Category-aware decay curves
* Real-time dynamic pricing
* Urgency-based marketplace discovery
* Claim & pickup workflow
* Waste diversion and value recovery tracking

### Current Prototype

The prototype demonstrates the complete loop:

**LIST → UNDERSTAND → PRICE → DECAY → DISCOVER → CLAIM → PICK UP → RESCUE**

Built as an exploratory prototype for testing the idea of **time-sensitive, AI-driven marketplaces for surplus resources.**
